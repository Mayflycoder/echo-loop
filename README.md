# Echo Loop V2

A one-thumb mobile browser game where every route you take returns as a moving obstacle in the next loop.

## Play

Open `index.html` in a browser, or enable GitHub Pages for the repository.

### Controls

- Mobile: drag anywhere to move the white core
- Desktop: mouse drag, arrow keys, or WASD
- Spacebar: pause/resume

### Rules

1. Collect at least one pink orb before the loop timer expires.
2. At the end of each loop, your route becomes a moving echo.
3. Touching an echo ends the run.
4. Collect orbs quickly to build the Flow multiplier.
5. Collect three or more orbs in one loop for a Perfect Loop bonus.

## Version 2 features

- Progressive difficulty from 7-second to 5-second loops
- Flow combo scoring up to x5
- Perfect Loop bonuses
- Highlighted collision replay
- Touch sensitivity settings
- Sound, vibration, particles, and optional screen shake
- Local high scores and playtest statistics
- Native score sharing where supported

## Deploy with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save and wait for GitHub to publish the site.

The game has no dependencies and runs entirely from this single HTML file.
